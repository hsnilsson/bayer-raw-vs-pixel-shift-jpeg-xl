# Archival value metrics

Archival usefulness is the research question, not a scalar score produced by this experiment. The [methodology](METHODOLOGY.md) defines the current calculations, and the [report](site/index.html) publishes all scopes and denominators.

1. Establish capture eligibility, source precision/profile, metadata preservation and exact retained bytes.
2. Compare each primary candidate with its own compressed RAW61 byte budget, without a tolerance allowance.
3. Report native color and native structure comparisons separately, conditional on accepted registration. Do not replace them with reduced-frame agreement.
4. Retain all approved crop outcomes, including failed or undefined comparisons. Aggregate per frame and distinguish repeated distances from independent captures.
5. Treat the DNG 200 MiB technical route separately. Camera-channel differences are not CIEDE2000, and technical readability is not a quality verdict.

PS16 is the comparison reference, not scene truth. High-pass agreement can reflect grain, noise, registration and interpolation as well as useful film information. No metric here proves that an error is invisible, establishes a universal negative-inversion tolerance, or authorizes source deletion. A calibrated application-specific rendering comparison and independent visual judgment would be needed for stronger archival recommendations.
