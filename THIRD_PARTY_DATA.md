# Third-Party Data

The repository license covers the original project code and documentation. It
does not relicense third-party test images, reference targets, downloaded source
files, or derivatives generated from those files.

## FADGI/OpenDICE

FADGI/OpenDICE target files and reference profiles are used as public,
standardized test material. Keep the original source sidecars generated by
`scripts/download_testdata.py` next to downloaded files.

Before redistributing these files or derivatives, verify the current rights and
usage guidance from the source project.

## Library of Congress

The Library of Congress sample images used by this project are selected because
their item pages indicate public-domain or no-known-restrictions status. The
download script writes `.source.json` sidecars for traceability.

Before redistributing the files or derived figures, verify the individual LOC
item page. Rights metadata can vary by item and can change as catalog records
are updated.

## Generated Figures

Generated panels under `docs/figures/` may include visual derivatives of public
test images. Treat those figures as documentation of this project, but check the
underlying source-image rights before reusing them elsewhere.

## Repository Storage Decision

Large public TIFF test files are intended to be included through Git LFS so the
public results can be reproduced without relying only on future availability of
the upstream downloads. Source sidecars and manifests should still be kept.

## Private Data

Private scans, raw files, DNG files, FilmLab exports, and local experiment output
are intentionally excluded from Git by `.gitignore` and by the publication audit.
