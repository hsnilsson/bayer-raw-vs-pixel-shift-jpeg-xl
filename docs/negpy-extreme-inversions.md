# Inversion stress modes

The earlier NegPy-derived public mode is withdrawn from the current report because its source-color interpretation was not validated. It does not supply current numerical or visual evidence.

The [current viewer](../site/index.html#visual) instead offers five explicitly defined, reference-derived linear-light modes. Hard density inversion and its shadow-recovery variant are mathematical edit-sensitivity proxies. They are not labeled as NegPy, a film profile or a calibrated negative conversion. All inputs share the same recipe, and exposure acts before the transformation in linear light. See [methodology](../METHODOLOGY.md).
